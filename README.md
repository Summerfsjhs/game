## 💡 開發緣由與動機

### 為什麼要打造這款遊戲？
傳統的 3D 第一人稱射擊遊戲（FPS）往往需要動輒數十 GB 的安裝包與高階顯示卡硬體支援，這讓玩家想在課餘或工作空檔與朋友快速來場「1v1 槍法單挑」時，面臨極高的時間與設備門檻。

**CYBER STRIKE 3D** 的誕生正是為了解決這個痛點，基於以下三大核心動機而開發：
1. **零門檻即時競技（Zero-Friction Gaming）**：完全基於現代瀏覽器原生技術（WebGL + HTML5）構建，無需任何編譯或安裝步驟，只要打開網址、輸入房號，3 秒內即可與朋友展開藍紅陣營對決。
2. **純前端單一檔案的極限探索（Single-File Architecture）**：挑戰在不使用大型商業遊戲引擎（如 Unity / Unreal）的前提下，僅靠純 JavaScript 與 Three.js，從零手寫出具備 **AABB 實體碰撞滑行、Raycast 彈道遮蔽、重力跳躍物理與動態 AI** 的完整 3D 射擊架構。
3. **緊湊刺激的 1v1 戰術博弈**：捨棄傳統網頁遊戲「無腦割草刷小怪」的單調設計，轉而專注於**高張力的 1v1 單挑對決**，結合地圖掩體走位、彈匣換彈節奏與單局經濟買槍系統，讓每一發子彈與每一次掩體移動都充滿戰術價值。

## 🚀 開發進化歷程

本專案採用敏捷迭代方式開發，從最初的基礎 3D 視角逐步演進為支援跨裝置即時對決的多模式戰術競技場：

| 開發階段 | 版本里程碑 | 核心技術突破與實裝內容 |
| :--- | :--- | :--- |
| **Phase 01** | **建立 3D 基礎物理空間** | • 導入 `Three.js` 構建 WebGL 3D 渲染管線與工業風競技場光影。<br>• 實作 `PointerLock API` 360 度第一人稱視角控制。<br>• 建立 `WASD` 移動與 `Space` 重力跳躍滯空物理系統。 |
| **Phase 02** | **單局戰術商店與軍火庫** | • 新增 `[B]` 鍵彈出式「單局戰術補給商店」，導入擊殺獎金經濟機制。<br>• 實裝 4 把特色槍械（手槍、雙持 UZI、全自動霰彈、電磁雷射槍）。<br>• 確立「彈匣需換彈、後備總彈藥無限 ($\infty$)」的爽快射擊節奏。 |
| **Phase 03** | **多兵種動態成長 AI 與物理遮蔽** | • 實作 **AABB 邊界盒碰撞檢測**，徹底解決玩家與 NPC 穿牆問題並支援貼牆滑行。<br>• 導入 **Raycast 射線彈道阻擋**，子彈擊中貨櫃與掩體會生成金屬火花與彈痕。<br>• 新增 4 大特種兵種隨機抽籤機制，隨局數動態提升敵軍血量、火力與 AI 準度。 |
| **Phase 04** | **多重遊戲模式與跨裝置連線** | • 擴充「1v1 標準對決」、「無盡 Boss 挑戰」與「軍火庫升級模式」。<br>• 導入雲端即時同步架構，支援透過**極簡房號**進行跨裝置 P1 藍隊 vs P2 紅隊真人單挑。<br>• 加入全螢幕戰鬥切換與動態戰術 HUD 介面。 |

## 🎮 遊戲核心特色

### 1. 🌐 極簡房號跨裝置 1v1 連線對決
* **無縫雙人同步**：房主點擊「創建房間」生成專屬房號，朋友輸入房號即可建立跨裝置即時連線，自動停用單機 AI 並切換為真人對決模式。
* **鮮明陣營識別**：房主（P1）身著**深藍戰術裝甲與青光夜視鏡**，客隊（P2）身著**赤紅戰術裝甲與琥珀夜視鏡**，並即時同步移動座標、跳躍動作、開火彈道與勝負比數。

### 2. 🎯 三大競技遊戲模式
* **⚔️ 1v1 標準對決（Standard Duel）**：經典單挑模式，每局隨機遭遇不同兵種的特種兵，每逢第 5 局將迎戰巨型指揮官 Boss。
* **👹 無盡 Boss 挑戰（Infinite Boss Rush）**：跳過所有常規士兵，每一局直接面對高血量、重火力的綠光巨型指揮官，考驗極限走位與換彈時機。
* **🔫 軍火庫升級模式（Gun Game）**：每成功擊殺一名敵人，系統將自動為你解鎖並切換至下一把更強大的武器，體驗從手槍一路進化至電磁雷射槍的快感。

### 3. 🛡️ 擬真 3D 物理與戰術掩體系統
* **實體牆壁擋子彈**：場地中央配置大型戰術貨櫃、水泥半牆與木箱堆疊。所有子彈均經過 `THREE.Raycaster` 精準判定，擊中掩體會立即阻擋傷害並噴發金色金屬火花與彈痕。
* **高階 AI 反擊邏輯**：敵軍具備動態追蹤與預判瞄準演算法，隨著局數推進，AI 的開槍冷卻時間會縮短，且子彈擴散角（Spread）會大幅收斂，逼迫玩家善用掩體與跳躍閃避火網。

## ⌨️ 操作按鍵與啟動指南

### 基礎控制按鍵
| 按鍵組合 | 戰術動作說明 |
| :--- | :--- |
| **`W` `A` `S` `D`** | 前後左右戰術移動（支援貼牆滑行） |
| **`Space` (空白鍵)** | 戰術跳躍（支援重力與滯空物理） |
| **`滑鼠移動 / 左鍵`** | 360 度第一人稱視角瞄準 / 開火射擊 |
| **`R`** | 更換彈匣（後備總彈藥無限 $\infty$） |
| **`B`** | 開啟 / 關閉「單局戰術補給商店」 |
| **`P` / `ESC`** | 開啟遊戲暫停選單與局數重置 |

### 🚀 本機與部署啟動方式
本專案採用純前端單一檔案架構（HTML5 + Tailwind CSS + Three.js），**無需安裝 Node.js 或任何建置工具**：

1. **複製專案原始碼**
   ```bash
   git clone https://github.com/your-username/cyber-strike-3d.git
   cd cyber-strike-3d
   ```
2. **直接開啟遊玩**
   * 使用任意支援 WebGL 的現代瀏覽器（Chrome、Edge、Firefox、Safari）直接雙擊開啟 `index.html`。
   * 或透過 VS Code 的 `Live Server` 擴充套件啟動本地預覽。
3. **進入全螢幕對戰**
   * 點擊畫面中央的 **「進入戰術競技場」**，系統將自動鎖定滑鼠游標並切換至全螢幕戰鬥模式。

* **3D 渲染與物理層 (`Three.js r128`)**：

* **UI 與視覺特效層 (`Tailwind CSS` + `Lucide Icons`)**：
  * 採用 Glassmorphism 毛玻璃設計風格，搭配動態準心擴散、紅色受擊暗角（Damage Vignette）與命中 X 標記（Hit Marker）。
* **多人連線同步層 (`Cloud Realtime Sync`)**：
  * 透過無狀態即時文件與事件集合監聽，實現低延遲座標插值同步與開槍/陣亡事件廣播。
